# Two appendix pairs for the conditional theorem

The earlier four-panel audit is separated into `feedback_force_check`
(premise and effective-force evolution) and `population_error_check`
(RMS displacement and output-error floors). Both are vector PDFs with PNG
and SVG companions, set at 5.5-inch width. Labels and margins were checked
visually; no four-panel composite is generated by this version.

The numerical calculation is unchanged: six width-705 targets, seed 30,
restart at 20k, 100k further GD updates at rate 0.002, and the common allowance
$B_t=4d_{\rm dir}(0)t$. The helper checks the sampled feedback premise,
force envelope, output floor, and endpoint RMS-displacement inequality on
each effective-flow path. All checks passed. GD is an empirical comparison;
the plotted bounds set tracking and discretization disturbances to zero.

The maximum allowance usage remains 0.543510, the minimum conditional relative
error floor is 0.392885, and the largest RMS-displacement allowance is
0.000773921. Comparison with the earlier numerical record showed only
last-bit floating-point differences. RMS displacement is measured from the
restart and is distinct from the RMS levels in the opening observation.
