Solid spectrum: discrete kernel, calculated from the feature-matrix singular values. Dashed spectrum: integral kernel on the same training inputs; values below its FP64 Gram-matrix resolution are omitted. Both spectra show λi/λmax. Exact structural zero eigenvalues lie off the logarithmic axis.

Dotted lines: least-squares fits of log10(λi/λmax) = a + bi versus rank i. The slope b is in decades per rank; the fitted successive-eigenvalue ratio is λi+1/λi ≈ 10b. R² measures fit quality in log space. Both fits use the same ranks, excluding unresolved integral eigenvalues and values below the visible 10−16 limit.
