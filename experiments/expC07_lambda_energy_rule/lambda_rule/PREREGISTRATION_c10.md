# expC10 pre-registration: the two-wall rule on held-out targets, fp64 and fp32

Written 2026-09-08 before any solve of this experiment. The rule under test is `docs/lambda_two_wall_rule.md` exactly as it stands; that document is not edited after this file is written, and nothing in this file is edited after `predictions.json` is generated (its SHA-256 is recorded at the bottom by `predict.py`).

## Hypothesis (one)

H1. For a target that was never used in developing the rule, and given only the activation, the width $N$, the working precision $\varepsilon$, and the target's band edge $\theta_B$, the bandwidth $\lambda^\star=\arg\min_\lambda\,[E_A(\lambda)+E_C(\lambda)]$ achieves an error within the criteria below of the best error attainable at any $\lambda$ on that cell, at both fp64 and fp32.

Secondary, pre-registered, evaluated on the same curves with no new runs: (S1) the rule's predicted error $E^\star=E_A(\lambda^\star)+E_C(\lambda^\star)$ against the measured minimum; (S2) robustness to a misstated band edge, the rule evaluated at $3\theta_B$ and $\theta_B/3$; (S3) descriptive comparison with the activation-only constant $A_K(\lambda)=\varepsilon$. None of S1 to S3 can change the verdict on H1.

## The rule, frozen

$E_A(\lambda)=\Lambda_r(\theta_B;\lambda)^{1/2}$, $\Lambda_r=S/(1+S)$, $S=\sum_{0<|m|\le8}t_m^2$, $t_m=\dfrac{\widehat K((\theta_B+2\pi m)/\lambda)}{\widehat K(\theta_B/\lambda)}\Big(\dfrac{\theta_B}{\theta_B+2\pi m}\Big)^r$.

$E_C(\lambda)=c\,\varepsilon\Big(1+W\,\dfrac{\theta_B^{\,r}}{\lambda^{r-1}\widehat K(\theta_B/\lambda)}\Big)$, $c=10$, $W=N+2R+1$, $R=32$.

$\lambda^\star=\arg\min_{\lambda\in\mathrm{geomspace}(0.03,1.5,600)}\,[E_A+E_C]$; $E^\star$ the minimum value. Kernels: tanh $r=1$, $\widehat K(\xi)=(\pi\xi/2)/\sinh(\pi\xi/2)$; gelu $r=2$, $(1+\xi^2)e^{-\xi^2/2}$; swish $r=2$, $\pi^2\xi^2\cosh(\pi\xi)/\sinh^2(\pi\xi)$. Precision: $\varepsilon=2^{-52}$ (fp64), $2^{-23}$ (fp32), i.e. `numpy.finfo(dtype).eps`, which is also gelsd's default cutoff. $\theta_B=2\Omega/N$ with $\Omega$ the target's band edge in rad per unit $x$, defined per family below.

## Held-out targets

Generated by `targets.py` from `numpy.random.default_rng(20260908)`, in this order, and not inspected before the run. Twelve targets.

- **F1, random trigonometric polynomials** (band edge exact): $f(x)=\sum_{k=1}^{K}a_k\sin(k\pi x+\phi_k)$, $a_k\sim U(0.2,1)$, $\phi_k\sim U(0,2\pi)$; two draws each for $K\in\{2,8,32\}$. $\Omega=K\pi$.
- **F2, random rational functions** (band edge by the 95% energy rule): $f(x)=\sum_{j=1}^{J}c_j\,\dfrac{s_j}{(x-p_j)^2+s_j^2}$, $J\sim U\{1,2,3\}$, $c_j\sim U(-1,1)$, $p_j\sim U(-0.8,0.8)$, $\log s_j\sim U(\log0.05,\log0.5)$; six draws. Each term has the closed-form transform $c_j\pi e^{-s_j|\omega|}e^{-i\omega p_j}$, so $|\hat f(\omega)|^2$ is explicit; $\Omega$ is the smallest frequency containing 95% of $\int_0^\infty|\hat f|^2d\omega$, found by bisection on the closed form.

The band edge given to the rule is exactly $\Omega$ (H1) or $3\Omega$, $\Omega/3$ (S2).

## Cells and measurement, frozen

Activations tanh, gelu, swish; widths $N\in\{64,128,256,512\}$; precisions fp64, fp32; the 60-point $\lambda$ grid $\mathrm{geomspace}(0.03,1.5)$ of expC08/expC09. Measured side identical to expC09: uniform centers $-1+kh$, $h=2/N$, halo $R=32$, $\gamma=\lambda/h$, augmented $[\Phi,\mathbf 1]$ solved by `scipy.linalg.lstsq(lapack_driver="gelsd")` in the stated dtype (features, right-hand side and solve all in that dtype, default cutoff) on $\max(2003,2W+3)$ uniform points; the fitted network is evaluated in the same dtype on 4001 uniform points and the residual against the fp64 target is measured in fp64; metric rel $L_2$. 12 targets $\times$ 3 activations $\times$ 4 widths $\times$ 2 precisions $=288$ cells, 60 solves each.

A cell is **resolved** if $q=\theta_B/\pi\le0.25$ (at least 8 cells per shortest wavelength) and its measured minimum is below $10^{-6}$ (fp64) or $10^{-3}$ (fp32); **under-resolved** if $q>0.25$ and the minimum is below those thresholds; cells whose minimum is above the threshold are reported but not scored (the target is not resolved at any $\lambda$).

Per cell the measured curve is smoothed by a 5-point running median in $\log$ (as in expC08/09); $E_{\min}$ is its minimum; $E(\lambda^\star)$ is read by log-interpolation. **Regret** $\rho=E(\lambda^\star)/E_{\min}$.

## Pass criteria for H1, fixed now

Evaluated separately for fp64 and fp32.

- Resolved cells: median $\rho\le2$ and 90th percentile $\rho\le10$.
- Under-resolved cells: 90th percentile $\rho\le10$.

H1 passes at a precision if both hold there. There is no partial pass. If H1 fails, the failure is reported with the cells responsible and the theory note is not revised in this experiment.

Secondary reporting (no verdict attached): S1, the fraction of cells with $E^\star$ within a factor 10 of $E_{\min}$; S2, the regret statistics of the rule at $3\Omega$ and $\Omega/3$; S3, the same statistics for the constant $A_K(\lambda)=\varepsilon$.

## What will not be done

No other activations, halos, sampling densities, solvers, extensions, or targets. No change to $c$, the $\lambda$ grid, the smoothing, the thresholds, or the criteria. No selection among cells after the fact beyond the resolved / under-resolved split defined above. If a bug in the measurement code is found, the fix is recorded in the writeup and the whole sweep is rerun; the predictions file is not regenerated.
